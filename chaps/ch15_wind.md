---
第15章　風を通す ── 立体の風洞
---


前の本の第 18 章では、平面のペンローズに風を通し、物体のまわりに出る横向きの力を見ました。対称な物体では横向きの力がちょうど 0 になり、出っ張りをつけると力が出て、鏡写しにするとちょうど逆向きになりました。この章では、同じことを立体のペンローズで行います。

## 鏡で対称な立体のペンローズ

横向きの力がちょうど 0 になることを確かめるには、担体そのものが鏡に映して自分に重なる必要があります。

第 12 章の立体のペンローズは、窓の位置を少しずらす量 γ を一般の値にしていたので、鏡に映すと別の並びになります。そこで γ を、鏡で変わらない値に選び直しました。鏡は、真上の軸 e0 と e5 を含む面での映しで、6 本の軸では e1 と e4、e2 と e3 の入れ替えです。γ の e1 と e4、e2 と e3 の値をそろえると、窓の位置も鏡で変わりません。

このとき、窓の境目にちょうど乗る六面体が出てきます。境目にちょうど乗る六面体は入れないことにしました。こうすると、六面体の集まりは鏡でちょうど自分に重なり、どの面も 2 個以下の六面体にしか属しません。境目の六面体の分だけ、ところどころに小さなすき間が残ります。

## 風と物体

風は x の向き（鏡の面の中）に吹かせます。左端の厚さ 2 の層にある六面体に、左側の隣の面から値 1 を入れ、第 12 章と同じ規則で値を渡していきます。入れる面の集まりも、鏡で対称です。

物体は、六面体を取り除いた穴です。

- 対称な球：鏡の面の上の点を中心に、半径 1.6 の中の六面体 20 個
- 出っ張り：球に、鏡の片側の小さな球を足したもの（24 個）
- 鏡写し：出っ張りを鏡に映したもの（24 個）

横向きの力 A は、鏡の上側の六面体と、それを鏡に映した下側の六面体で、入ってきた値の二乗の差を足し合わせたものです。

## 確かめたこと

基準を先に決めてから走らせました（ch15_wind.py）。

| 番号 | 何を見たか | 結果 |
|---|---|---|
| R0 | 担体 | 六面体 3149 個が、鏡に映すとちょうど自分に重なる。どの面も 2 個以下の六面体にしか属さない。風の入口 281 面も鏡で対称 |
| R1 | 和と二乗和 | 3 通りの物体すべてで、24 歩のあいだ、和は毎歩ちょうど 60 倍、二乗和は毎歩ちょうど 3600 倍 |
| R2 | 逆向き | 3 通りすべてで、逆に 24 歩走らせると最初に戻る |
| R3 | 対称な球の A | 24 歩のすべてで、ちょうど 0 |
| R4 | 出っ張りと鏡写しの A | 出っ張りでは A が 0 でなく、鏡写しでは 24 歩のすべてでちょうど −A |
| R5 | 重ね合わせ | 入口を二つに分けて別々に流した風の和が、一緒に流した風と、12 歩目のすべての辺で一致する |

出っ張りの A は、風が物体に届くまでの 10 歩は 0 で、そのあと正と負を行き来します。符号は歩ごとに次のとおりでした（左から 0 歩目）。

0000000000 ++++++ −−− ++++ −−

鏡写しの物体では、この符号がすべて逆になります。

### 負の対照

窓のずらし量 γ を第 12 章と同じ（鏡で変わる）値にすると、担体は鏡で自分に重ならず、対称な球でも A は 25 歩のすべてで 0 になりません。R3 は NG を返します。A がちょうど 0 になるのは、担体と物体と風の三つがすべて鏡で対称なときだけです。

## 既存の数学とのつながり

観察者側の整理として書いておきます。鏡に対称な物体に対称な流れを当てると、横向きの力（揚力）は 0 になり、形を非対称にすると力が生まれる、というのは流体力学でもおなじみの見方です。ここでは、それを流体の方程式としてではなく、整数の波の値の二乗の差として、ちょうど 0、ちょうど逆向き、と確かめています。

## まとめ

立体のペンローズを鏡で対称に作り直し、左から風を通しました。対称な球のまわりでは横向きの力は毎歩ちょうど 0、出っ張りをつけると力が生まれ、鏡写しにすると毎歩ちょうど逆向きになります。風は重ね合わせることができ、逆に走らせれば元に戻ります。前の本の平面の風洞は、立体でもそのまま成り立ちます。
