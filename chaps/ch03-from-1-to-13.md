第3章　1から13まで積む ── 奇数はジグザグ、偶数はまっすぐ

前の本の第 1 部では、扇形の三角形の段 n に円環を n 個並べ、1 から 13 までの整数を平面に写しました。奇数の段はジグザグ、偶数の段はまっすぐに並びます。この章では、同じ並びを 30 面体で組みます。

## 一歩を整数で決める

第 2 章の輪で、同じ段の隣どうしも面で接していました。その一歩は高さの組が (0, 0) で、水平です。

u₀ ＝ (0, 2, 2, 0, −2, −2)

u₀ の e1〜e5 を一つずらした u₁ は、真上から見て 72° 回った向きです。二つのまん中の向き（u₀ から 36°）には、w ＝ (0, 0, 2, 2, −2, −2) があります。三つとも長さは接する距離と同じで、√5 倍した長さの二乗の組は (16, 32) です。

数 n を、n 個の 30 面体の鎖で表します。

- 奇数：u₀ と u₁ を交互に進む。折れ角は 108° のジグザグ
- 偶数：w だけで進む。まっすぐの鎖

## 確かめたこと

基準を先に決めてから走らせました（ch03_stack.py）。

| 番号 | 何を見たか | 結果 |
|---|---|---|
| S1 | 鎖の隣どうしの共有頂点 | n ＝ 1〜13 のすべてで 4 個（面で接する） |
| S2 | 隣でない組 | 共有頂点は 0 個。中心どうしの距離はどれも接する距離より遠い |
| S3 | 中心の高さ | すべて (0, 0)。どの鎖も水平な面に乗る |
| S4 | 折れ角 | 奇数は 108° の組 (−4, −12) だけ、偶数は 180° の組 (−16, −32) だけ |
| S5 | 30 面体の数 | 1 ＋ 2 ＋ … ＋ 13 ＝ 91 個 |

折れ角は、続く二歩の内積を √5 倍した (√5 の係数, 整数) の組で見ています。(−4, −12) は cos 108°、(−16, −32) は cos 180° にあたります。

距離の比べ方も整数だけです。二つの長さ x√5 ＋ X と y√5 ＋ Y の大小は、(x − y)√5 と (Y − X) の大小になり、両辺の符号を見てから二乗どうしを比べれば決まります。

段 1, 1, 2, 3, 5, 8, 13 の鎖は、30 面体の数が前の二つの鎖の和になっています。

同じ向きに曲がり続けて u₀, u₁, u₂, u₃, u₄ と進むと、5 歩で元に戻ります。これは第 2 章の、上の段 5 個の五角形の輪です。ジグザグは左右に交互に曲がるので閉じずに伸び、同じ向きに曲がり続けると 5 歩で閉じます。

### 負の対照

u₀ と u₂（144° 回った向き。折れ角は 36°）を交互に進むと、一つ飛びの中心の長さの組は (8, 8) になります。これは接する距離 (16, 32) より近く、30 面体どうしが食い込みます。S2 は NG を返します。

## まとめ

1 から 13 までの整数は、30 面体 91 個で、前の本の平面と同じ並びに組めます。奇数はジグザグ、偶数はまっすぐで、どの鎖も水平な面に乗ったまま、面で接して食い込みません。使う一歩は u₀、u₁、w の 3 本の整数の組だけです。並びは平面のままで、立体に上げても形は変わりません。
